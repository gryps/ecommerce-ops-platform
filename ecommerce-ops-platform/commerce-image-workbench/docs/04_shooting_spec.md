# 拍摄规范

## 拍摄目标

参考图不是为了好看，而是为了让 AI 模型准确理解产品。

需要拍清楚：

- 整体轮廓
- 正反结构
- 左右关系
- 厚度层次
- 材质纹理
- 装饰数量
- 流苏位置
- 尺寸比例

## 每个产品必拍 8 张

### 01 正面全貌图

装饰面朝上，完整拍入画面。

要求：

- 产品不裁切
- 背景干净
- 产品占画面约 70%
- 光线均匀

### 02 背面全貌图

翻到背面拍摄。

用途：

- 帮助模型理解连接件
- 帮助模型理解簪杆背面结构
- 避免佩戴图结构错乱

### 03 左 45 度图

把产品斜放，簪杆与画面边缘约 45 度。

示意：

```text
\ 发簪
```

用途：

- 看清装饰层次
- 看清前后关系
- 看清簪杆延伸方向

### 04 右 45 度图

反方向斜放。

示意：

```text
/ 发簪
```

用途：

- 补充另一侧结构
- 降低左右结构被模型误解的概率

### 05 侧面厚度图

从侧边拍摄。

用途：

- 看清花朵、珠子、吊坠的厚度
- 看清流苏挂点
- 看清产品是否有弯曲

### 06 头部装饰细节图

近距离拍摄发簪头部。

重点：

- 花朵
- 珠子
- 金属雕花
- 玉石
- 蝴蝶
- 连接件

### 07 材质/流苏细节图

近距离拍材质或流苏。

重点：

- 珍珠光泽
- 金属颜色
- 木纹
- 玉石纹理
- 流苏数量
- 吊坠形状

### 08 尺寸比例图

旁边放尺子、手或标准参照物。

用途：

- 防止 AI 把发簪生成得过大或过小
- 辅助佩戴图比例判断

## 拍摄设备

推荐：

- 手机或相机
- 三脚架
- 白色/浅灰背景纸
- 柔光灯
- 尺子
- 产品编号标签

## 文件命名

```text
products/
  HZ001/
    01_front.jpg
    02_back.jpg
    03_left_45.jpg
    04_right_45.jpg
    05_side.jpg
    06_detail_head.jpg
    07_detail_material.jpg
    08_scale.jpg
```

## 注意事项

- 不要只拍一张正面图。
- 不要使用复杂背景。
- 不要强烈偏黄或偏蓝。
- 不要让产品出画。
- 不要让产品太小。
- 不要混用不同产品的图片。
- 不要随意命名文件。
