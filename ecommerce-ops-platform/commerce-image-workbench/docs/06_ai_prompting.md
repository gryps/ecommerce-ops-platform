# AI 模型与提示词方案

## 模型分工

### 即梦 / Seedream

适合：

- 视觉方向探索
- 国风氛围
- 佩戴场景
- 高级感环境图
- 风格打样

不建议第一阶段完全依赖它做批量流程，因为接口、稳定性和批量管理需要单独确认。

### 通义万相

适合：

- 批量商品图
- 商详图
- 标准化流程
- API 化生产

### 腾讯混元

适合：

- 商品换背景
- 模特佩戴图
- 环境图补充
- 备用批量生成方案

## 提示词基本结构

```text
任务目标：
输入参考图是一款发簪产品，请生成电商商品图。

产品信息：
材质：{materials}
颜色：{colors}
风格：{styles}
结构：{structure}

画面要求：
{template_scene}

保真要求：
必须保持发簪的整体造型、颜色、材质、簪杆长度、装饰数量、流苏位置。

禁止：
{preserve_rules}
不要增加珠子，不要改变流苏数量，不要改变颜色，不要改变发簪结构。
```

## 白底主图模板

```text
生成一张电商白底商品主图。画面干净，产品居中，背景纯白或接近纯白，柔和摄影棚光线，产品边缘清晰，材质细节清楚。

必须保持输入发簪的真实结构、颜色、材质、装饰数量、流苏位置和簪杆长度比例。

不要添加额外装饰，不要改变珠子数量，不要改变金属颜色，不要改变流苏方向，不要生成多余产品。
```

## 中式环境图模板

```text
生成一张高级中式风格电商环境图。发簪放置在浅色绸缎、木质首饰盘或简洁梳妆台上，画面优雅、干净、有自然柔光。

保持发簪本体与参考图一致，包括形状、颜色、材质、装饰数量、流苏位置和簪杆长度比例。

背景可以有中式氛围，但不要喧宾夺主，不要遮挡产品，不要改变产品结构。
```

## 佩戴图模板

```text
生成一张发簪佩戴图。模特为黑色或深棕色盘发，发簪自然插入发髻，露出完整装饰部分和合理长度的簪杆。画面为电商商品展示风格，干净、自然、真实。

必须保持发簪产品与参考图一致，包括装饰数量、流苏位置、颜色、材质和整体比例。

不要改变发簪结构，不要把发簪变成发夹，不要增加珠子，不要改变流苏数量，不要遮挡主要装饰。
```

## 手机竖屏商详图模板

```text
生成一张 9:16 手机竖屏电商详情图。画面上方展示发簪整体，下方留出可排版空间或展示材质细节，整体适合淘宝、抖音、小红书商品详情页。

保持产品真实结构和材质，不要改变颜色、装饰数量、流苏位置和簪杆比例。

画面高级、清晰、干净，不要出现无关文字、水印、logo。
```

## 审核检查点

每张生成图都要检查：

- 是否仍是同一支发簪
- 颜色是否一致
- 珠子数量是否一致
- 流苏数量和位置是否一致
- 簪杆长度是否合理
- 材质是否被改掉
- 背景是否干净
- 是否适合电商上架
