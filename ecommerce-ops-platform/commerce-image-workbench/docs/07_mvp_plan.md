# MVP 开发计划

## MVP 原则

第一版先解决流程管理，不急着接所有模型 API。

优先实现：

- 产品库
- 参考图管理
- 拍摄完整性检查
- 提示词模板
- 生成任务记录
- 人工审核
- 本地数据导出

## 阶段 1：本地工作台

形式：

- 本地 Web 应用
- 数据先存本地 JSON 或轻量数据库
- 图片按产品编号进入目录

功能：

- 新建产品
- 编辑产品资料
- 上传 8 张参考图
- 显示缺图状态
- 选择图片模板
- 生成提示词
- 手动记录在哪个平台生成
- 上传生成结果
- 标记审核状态
- 导出素材包

## 阶段 2：半自动 AI 生产

功能：

- 对接通义万相 API
- 对接腾讯混元 API
- 保留即梦/Seedream 的手动生成记录
- 批量创建生成任务
- 批量下载结果

## 阶段 3：商详图组装

功能：

- 按模板选择可用图
- 自动生成手机竖屏详情图
- 输出单图或多图
- 输出淘宝/抖音/小红书素材目录

## 推荐技术路线

### 前端

- React
- TypeScript
- Vite

### 本地数据

第一版可选：

- IndexedDB
- 本地 JSON 文件
- SQLite

### 后端

第一版如果要做文件上传和导出，建议使用：

- FastAPI
- SQLite
- 本地文件存储

### 后续模型接口

- 通义万相 API
- 腾讯混元 API
- Seedream/即梦可用接口或人工流程

## 第一版页面

- 仪表盘
- 产品列表
- 产品详情
- 参考图上传
- 模板中心
- 提示词生成
- 任务列表
- 审核工作台
- 导出中心

## 第一版交付标准

- 可以创建并管理 150 个产品。
- 每个产品可以上传 8 张标准参考图。
- 系统能提示缺少哪些参考图。
- 可以根据产品信息生成提示词。
- 可以记录生成任务和审核状态。
- 可以导出产品素材目录。
