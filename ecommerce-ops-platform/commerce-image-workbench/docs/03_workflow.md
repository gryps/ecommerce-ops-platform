# 业务流程文档

## 总流程

```text
产品准备
  -> 标准拍摄
  -> 产品建档
  -> 参考图上传
  -> 拍摄完整性检查
  -> 选择生成模板
  -> 生成提示词
  -> AI 平台生成
  -> 回传结果
  -> 人工审核
  -> 可用素材归档
  -> 商详图输出
```

## 阶段 1：产品准备

为每个产品分配唯一编号。

示例：

```text
HZ001 珍珠流苏金色发簪
HZ002 木质雕花发簪
HZ003 蝴蝶玉石发簪
```

## 阶段 2：标准拍摄

每个产品拍 8 张参考图：

```text
01_front.jpg
02_back.jpg
03_left_45.jpg
04_right_45.jpg
05_side.jpg
06_detail_head.jpg
07_detail_material.jpg
08_scale.jpg
```

## 阶段 3：建档

录入产品信息：

```text
产品编号：HZ001
材质：合金、珍珠、流苏
颜色：金色、白色
风格：新中式、温柔、日常
结构：金色簪杆，头部三颗珍珠，右侧一条流苏
禁止：不要改变珍珠数量，不要改变流苏位置，不要改成银色
```

## 阶段 4：模板选择

按需要选择图片类型：

- 白底主图
- 环境图
- 佩戴图
- 商详图

## 阶段 5：生成提示词

系统根据产品档案和模板生成提示词。

操作员复制提示词到对应模型平台，或由后续 API 自动提交。

## 阶段 6：AI 生成

推荐模型分工：

- 即梦/Seedream：视觉方向、佩戴氛围、国风环境
- 通义万相：批量商品图、商详图
- 腾讯混元：商品换背景、模特佩戴图、补充出图

## 阶段 7：人工审核

审核重点：

- 发簪形状是否一致
- 珠子数量是否一致
- 流苏位置是否一致
- 簪杆长度是否合理
- 材质颜色是否准确
- 佩戴比例是否自然
- 背景是否适合电商

## 阶段 8：归档

可用结果按产品编号归档：

```text
outputs/
  HZ001/
    main/
    scene/
    wearing/
    detail/
    mobile_detail/
```

## 阶段 9：商详输出

每个产品建议输出：

- 1 张白底主图
- 2-3 张环境图
- 1-2 张佩戴图
- 2 张细节图
- 1 组手机竖屏商详图
