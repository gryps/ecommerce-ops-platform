# 产品需求文档

## 1. 产品库

### 需求

系统需要维护发簪产品档案。

### 字段

- 产品编号
- 产品名称
- 类目
- 材质
- 主色
- 辅色
- 风格标签
- 结构描述
- 卖点描述
- 禁止变形点
- 备注
- 创建时间
- 更新时间

### 说明

产品编号必须稳定，例如 `HZ001`、`HZ002`。后续图片、任务、导出文件都围绕产品编号组织。

## 2. 参考图管理

### 每个产品需要 8 张标准参考图

- 正面全貌图
- 背面全貌图
- 左 45 度图
- 右 45 度图
- 侧面厚度图
- 头部装饰细节图
- 流苏/珠子/材质细节图
- 尺寸比例图

### 功能

- 上传参考图
- 标记缺失图片
- 预览参考图
- 替换参考图
- 自动按类型命名

## 3. 图片类型模板

系统内置以下生成类型：

- 白底主图
- 浅色高级场景图
- 中式环境图
- 佩戴图
- 细节放大图
- 手机竖屏商详图

每个模板包含：

- 图片目标
- 构图要求
- 背景要求
- 光线要求
- 保真要求
- 负面提示词
- 推荐模型

## 4. 提示词生成器

### 输入

- 产品档案
- 参考图类型
- 图片模板
- 模型类型

### 输出

- 中文提示词
- 英文提示词
- 负面提示词
- 保真约束
- 人工检查点

## 5. 生成任务

### 字段

- 任务编号
- 产品编号
- 图片类型
- 模型
- 模板版本
- 提示词
- 输入参考图
- 输出图片
- 状态
- 审核结论
- 创建时间

### 状态

- 待生成
- 已生成
- 可用
- 需重做
- 废弃

## 6. 审核功能

审核人员需要能标记：

- 可用
- 颜色错误
- 结构错误
- 流苏错误
- 珠子数量错误
- 材质错误
- 比例错误
- 背景不合适
- 需重新生成

## 7. 导出功能

第一阶段支持导出：

- 单产品素材包
- 批量产品素材包
- 可用图片清单
- 生成任务记录
- 商详图素材目录
