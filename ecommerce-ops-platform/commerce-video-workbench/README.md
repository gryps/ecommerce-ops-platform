这是电商运营平台中的视频生产业务文档目录，用于沉淀当前有效的视频生产口径、流程、数据模型、模型调用和开发计划。

## 项目定位

电商视频生产工作台服务于短视频素材归类、内容文库沉淀、字幕/旁白生成、背景音乐管理和剪映专业版草稿组装。

当前业务边界是人工主导、系统辅助：

- 人工决定视频归属、产品标签、视频顺序、文案、字幕/旁白和背景音乐。
- 系统自动执行原视频移动/重命名、模型文案与语音辅助、音频提取和剪映草稿组装。
- 模型结果必须经过人工采纳或确认，不能直接进入生产草稿。
- 输出是可交给剪映专业版继续编辑的半成品草稿，不是 MP4 成片。

## 核心流程

1. 选择原视频。
2. 人工确认产品和标签。
3. 系统移动并重命名原视频。
4. 建立文案、旁白/字幕、背景音乐资源。
5. 人工选择生产素材。
6. 系统生成无视频轨道的剪映草稿。
7. 用户在剪映专业版中补充视频、裁剪、检查和发布。
