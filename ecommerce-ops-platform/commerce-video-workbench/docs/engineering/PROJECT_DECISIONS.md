# 视频自动化工作台：关键决策

> 更新时间：2026-08-07（Asia/Shanghai）
>
> 本文件只记录当前新流程仍有效、且仅看代码不容易理解的跨模块决定。

## 1. 自动化边界

- 人工决定视频归属、产品标签、视频顺序、文案、字幕/旁白和背景音乐。
- 系统只自动执行文件移动/重命名、模型文案与语音辅助、音频提取和剪映草稿组装。
- 系统不再自动筛选、粗剪、卡点、精修、渲染成片或判断热播。
- 模型结果必须经过人工采纳或确认，不能直接进入生产草稿。

## 2. 素材归类与文件所有权

- “确认归类”是原视频文件移动操作，不是复制或导入。
- 产品名称直接决定目标文件夹；产品名称与标签共同决定文件名。
- 标签跨产品通用，以“标签分类＋标签名称”共同唯一；标签分类是可维护的独立主数据。
- 归类是一次性文件操作，确认后只完成移动和重命名；不以历史记录禁止用户再次选择同一文件。
- 每条视频至少一个标签，并且同一标签分类下只能选择一个标签名称；一条视频可以同时拥有不同分类的标签。标签跨产品通用，不与产品建立专属关系。
- 路径和媒体校验在移动前完成；批量移动失败时回退本次已经移动的文件。
- 数据库保存本次移动前后路径；删除产品、标签分类或标签会删除对应主数据关系，但不处理磁盘文件。
- 生产只选择完整原视频，不再依赖人工粗剪片段或自动候选片段。

## 3. 文案与语音

- 框架功能及其当前数据库实体已经删除；历史迁移文件只用于旧库顺序升级。
- 文案库的“文案”同时包含短标题和长口播稿；字幕与旁白保留在独立标签页。
- 文案策略不再由人工维护。百炼根据参考文案自由分析语言、受众和专家角色，并自动生成 5 条；输入的参考原文视为人工提供的已采纳内容。
- 无输入推荐只使用全局已采纳文案；继续迭代沿用创建任务时冻结的参考语料、分析与角色，并使用人工采纳/不采纳反馈。
- 分析候选与文案库条目是独立实体：采纳时建立独立文案库条目。删除分析记录不得连带删除文案库内容，删除文案库内容也不得损坏迭代历史。
- 抖音视频、本地视频或本地音频转文案属于语音识别；文案生成旁白属于语音合成。
- 配音音色属于语音合成模型能力，不建立新的独立音色库存。
- 字幕配音固定从当前官方音色库按序号解析 voice 参数，不再混入模型系统音色或人工附加音色。
- 音色使用固定短句真实合成试听并采用单播放器；试听属于真实模型调用，列表读取不属于真实调用。
- 当前 Qwen-Audio-TTS Plus 的官方基础音色作为只读目录随项目保存，不创建可编辑音色实体；官方序号 1–597 是字幕配音的稳定人工选择键，后端以序号解析 voice 参数。
- 模型配音的输入文字本身就是已知字幕，不再用 ASR 识别合成结果；系统依据生成音频时长为原字幕生成时间轴。

## 4. 音乐

- 背景音乐是全局资源，支持上传和短视频链接音频提取。
- 音乐只保留试听、来源和自定义标签，不保存 BPM、节拍、重拍、波形或卡点分析字段。
- 链接提取失败仅影响当前资源，必须提示用户改用本地上传。

## 5. 剪映草稿

- 工作台生产结果是可交给剪映专业版继续编辑的无视频半成品草稿，不是 MP4 成片。
- 草稿冻结当次选择，后续修改资源库不改写已生成草稿。
- 工作台不生成视频素材或视频片段；为兼容当前剪映时间线，可保留空视频轨道。视频由用户打开剪映后自行添加、裁剪和排列。
- 所选文案和字幕使用独立文字轨道。文案按旁白真实音频或有效字幕结束时间显示；仅有文案或仅有背景音乐时最多显示 5 秒。字幕按确认时间轴排列；如果字幕时间轴异常长于旁白音频，则按旁白真实音频时长裁剪。旁白与背景音乐从 0 秒开始并保持原始长度。
- 草稿直接写入用户确认的剪映草稿目录，不生成 ZIP；旁白和背景音乐复制到草稿本地 `assets/audio`，音频轨道引用草稿内本地资源。
- 相同文案、旁白与字幕、背景音乐组合允许重复生成；重复生成前必须提示此前已使用次数，但不阻止继续生成。重复提示次数来自独立累计生成计数器，不随草稿记录删除而减少。重复提示计数器可以按当前组合复位，复位只记录计数基线，不删除草稿记录。
- 剪映草稿格式存在客户端版本差异，必须以当前实际安装版本进行最终业务验收。

## 6. 模型与日志

- 新流程统一配置为阿里云百炼兼容连接。
- 文案生成、音频转文案、字幕配音分别保存模型 ID，可共享连接和密钥；不再保存启用开关或附加音色 ID，配置完整即使用。
- 音色库试听首次生成后写入数据库并持久保存音频文件，后续试听复用库存文件，不重复调用模型。
- 文案生成包含文案分析、5 条迭代和字幕文案生成；语音模型包含 ASR 与 TTS 两个功能。
- 连接测试和模型/音色列表读取不是业务调用，不进入业务调用统计。
- 音色试听会真实生成短音频，进入业务调用日志；试听文件只用于本次响应，返回后立即清理，不进入旁白与字幕库。
- Qwen-Audio-TTS/CosyVoice 使用百炼工作区原生 `SpeechSynthesizer` 接口并下载非流式响应的临时音频；只有明确兼容 OpenAI TTS 的模型才走 `/audio/speech`。
- 真实生成、识别、合成的每次尝试继续记录脱敏日志；日志失败不得影响业务结果。

## 7. 历史兼容与删除

- 旧框架、粗剪、生产计划、成片、热播、自动混剪等退役数据和数据库对象已经物理删除。
- 当前 ORM 只声明现行业务实体；历史 Alembic 文件必须保留用于旧库顺序升级，但不会在当前
  数据库中保留退役表或字段。
- 模型调用日志清理由 Web 服务定时执行，不再部署独立 Worker 或 Redis。
- 已归类原视频属于用户素材盘，删除数据库记录不得隐式删除原视频。
- 背景音乐删除必须先检查剪映草稿引用；剪映草稿记录删除只删除工作台记录，不删除磁盘上的草稿文件夹。

## 8. 界面交互术语约定

- **模糊联想输入框**：适用于候选条目较多、主要依靠输入文字缩小范围的场景。用户输入后按相似度显示已有数据建议，但不提供独立的“展开全部”按钮。当前素材归类中的“产品名称”使用此交互。
- **可输入下拉框**：用于候选条目较少的场景。控件同时支持手动输入、输入时模糊筛选、点击箭头展开完整列表，以及选择新项目后直接覆盖已有文字。用户后续提出“使用可输入下拉框”时，默认采用这套交互，不使用仅依赖浏览器联想的 `datalist`。
- **系统原生文件选择器**：点击页面按钮后调用操作系统的文件选择窗口，而不是在网页内输入路径。当前“选择视频”使用其“Windows 原生多文件选择”形式，支持一次选择一个或多个视频。用户后续提出“使用系统原生文件选择器”时，单选或多选由业务场景决定；明确说“系统原生多文件选择器”时必须支持多选。

## 9. 高容量栏目布局约定

- 产品清单、素材清单、任务清单、批量编辑表格、结果审核列表、平台字段模板等以后可能增长到几十到几百项的栏目，默认使用页面主工作区或全宽区域。
- 这类栏目不得安排在窄侧栏、小卡片、压缩面板或装饰性容器里；侧栏只适合放筛选、状态、快捷操作和摘要。
- 批量生产流程中的清单和表格优先保证横向信息完整、批量选择、批量编辑、筛选、排序、分页或虚拟滚动空间。
- 如果一个区域承载实际业务处理，它的布局优先级高于说明文字和装饰视觉。
