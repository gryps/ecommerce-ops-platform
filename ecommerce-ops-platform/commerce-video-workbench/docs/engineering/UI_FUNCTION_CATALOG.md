## 1. 模糊联想输入框

- **适用场景**：候选条目较多，用户通常知道部分名称，需要通过输入快速缩小范围。
- **功能介绍**：支持手动输入；输入过程中按相似度显示已有数据建议；用户可以选择建议，也可以继续输入新内容；不提供独立的“展开全部”按钮。
- **当前实例**：素材归类中的“产品名称”；字幕配音中的“从文案库选择”（实时查询全部文案库，选择后填入旁白正文）。
- **调用说法**：`这里使用模糊联想输入框。`

## 2. 可输入下拉框

- **适用场景**：候选条目较少，既需要浏览完整列表，也需要手动输入或模糊筛选。
- **功能介绍**：支持手动输入、输入时模糊筛选、点击箭头展开完整列表，以及选择新项目后直接覆盖已有文字；重新选择时不要求先删除原内容。
- **当前实例**：素材归类中的“标签分类”和“标签名称”。
- **调用说法**：`这里使用可输入下拉框。`

## 3. 系统原生文件选择器

- **适用场景**：需要通过操作系统窗口选择本地文件，不适合要求用户手动输入文件路径。
- **功能介绍**：点击页面按钮后调用 Windows 系统文件选择窗口；可以按业务需要配置文件类型、单选或多选。
- **当前实例**：素材归类中的“选择视频”，当前使用多选形式。
- **调用说法**：`这里使用系统原生文件选择器。`

### 3.1 系统原生多文件选择器

- **适用场景**：一次需要选择多个本地文件。
- **功能介绍**：属于“系统原生文件选择器”的多选形式；必须允许在同一个 Windows 系统窗口中选择一个或多个文件。
- **当前实例**：素材归类中的“选择视频”。
- **调用说法**：`这里使用系统原生多文件选择器。`
