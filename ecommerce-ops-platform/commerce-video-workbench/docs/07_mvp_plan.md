# MVP 开发计划

## 1. 当前状态

视频生产核心功能已集成在统一运行项目：

```text
/mnt/e/codexwork/ecommerce-ops-platform/ops-workbench
```

已实现的主流程包括：

- 原视频归类、移动和重命名；
- 产品、标签分类、标签名称管理；
- 文案分析、候选生成、采纳和迭代；
- 音频转文案；
- 官方音色库、音色试听、字幕配音；
- 背景音乐上传、链接提取、试听和标签；
- 无视频轨道剪映草稿生成；
- 模型配置和真实调用日志。

## 2. MVP 阶段划分

### 阶段一：业务收口

目标：去掉旧自动混剪、粗剪、成片渲染等退役口径，只保留当前人工主导流程。

状态：已完成。

### 阶段二：素材归类

目标：

- 产品和标签主数据可维护。
- 系统原生多文件选择器选择原视频。
- 原视频按产品和标签移动、重命名。
- 批量失败可回退。

状态：已完成，仍需真实素材盘端到端验收。

### 阶段三：内容文库

目标：

- 文案分析和候选生成。
- 候选采纳、不采纳和继续迭代。
- 文案库独立维护。
- 音频转文案结果人工确认后保存。

状态：已完成，仍需更多真实素材和真实运营文案验收。

### 阶段四：语音与音乐资源

目标：

- 官方音色库可筛选、试听和复用。
- 字幕配音按音色序号生成。
- 背景音乐可上传、提取、试听、打标签。

状态：已完成，仍需真实百炼 TTS 和真实短视频链接覆盖验证。

### 阶段五：剪映草稿

目标：

- 检测和确认剪映草稿目录。
- 选择文案、旁白/字幕和背景音乐。
- 生成可被剪映专业版打开的半成品草稿。
- 重复组合提示和计数器复位。

状态：已完成，仍需当前安装剪映专业版的真实打开验收。

## 3. 后续优先事项

1. 使用真实素材盘验证批量移动、中文产品/标签、重名序号和失败回退。
2. 使用真实运营文案验证文案生成质量和迭代反馈效果。
3. 使用真实百炼 TTS 验证音色试听入库和字幕配音。
4. 使用真实短视频链接验证背景音乐提取失败提示和上传回退。
5. 使用当前剪映专业版打开生成草稿，确认轨道兼容性。
6. 将视频生产文档入口纳入统一平台 README 和项目记忆。

## 4. 暂不开发

- 自动选片。
- 自动粗剪。
- 音乐卡点。
- 系统内成片渲染。
- 热播追踪。
- 自动发布。
- 无人值守生产。
