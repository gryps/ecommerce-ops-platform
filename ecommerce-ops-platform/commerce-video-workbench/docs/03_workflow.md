# 业务流程文档

## 1. 总流程

```text
选择原视频
→ 人工确认产品和标签
→ 系统移动并重命名原视频
→ 准备文案、旁白/字幕、背景音乐
→ 人工选择草稿素材
→ 系统生成剪映专业版半成品草稿
→ 用户在剪映中继续编辑和发布
```

## 2. 素材归类流程

1. 用户进入“素材归类”。
2. 选择或新增产品名称。
3. 选择一个或多个原视频。
4. 为每条视频选择标签。
5. 系统校验：
   - 源文件存在；
   - 文件在允许目录边界内；
   - 扩展名和媒体信息可识别；
   - 每条视频至少一个标签；
   - 同一分类下没有多个标签；
   - 目标路径没有不可处理的重名冲突。
6. 系统创建产品目录。
7. 系统移动原视频并重命名。
8. 如果批量移动中途失败，回退本批次已经移动的文件。
9. 成功后记录归类信息，并在当前页提示本次移动结果。

## 3. 文案生产流程

### 3.1 有参考文案

1. 用户输入参考文案。
2. 模型分析语言风格、受众画像和专家角色。
3. 参考原文自动保存为已采纳文案。
4. 模型生成 5 条候选。
5. 用户逐条采纳或不采纳。
6. 全部审核完成后，允许继续迭代下一轮 5 条。

### 3.2 无参考文案

1. 用户不输入参考文案。
2. 系统从全局已采纳文案形成语料快照。
3. 模型基于已采纳语料分析和推荐。
4. 如果文案库为空，阻止生成并提示先输入参考文案。

## 4. 音频转文案流程

1. 用户提交抖音短链接、本地视频或本地音频。
2. 系统预处理音频为 16kHz 单声道 MP3。
3. 系统校验 5 分钟和 10MB 限制。
4. 调用百炼 `qwen3-asr-flash`。
5. 用户检查和修改识别结果。
6. 用户确认保存后，结果进入文案库。

## 5. 字幕配音流程

1. 用户手动输入文案，或从文案库联想选择。
2. 用户输入音色序号。
3. 系统解析序号对应的 voice 参数。
4. 调用字幕配音模型。
5. 系统根据合成音频时长生成字幕时间轴。
6. 用户试听、确认或删除结果。

## 6. 背景音乐流程

1. 用户上传本地音频/视频，或提交短视频链接。
2. 系统提取有效音频。
3. 如果链接提取失败，提示改用本地上传。
4. 系统拒绝接近全静音的音频。
5. 用户试听、改名、打标签。
6. 音乐入库后可用于剪映草稿。

## 7. 剪映草稿流程

1. 系统检测剪映专业版草稿目录。
2. 用户确认目录；未检测到时手动填写。
3. 用户选择文案、旁白/字幕和背景音乐，至少选择一种。
4. 系统检查相同组合此前生成次数。
5. 如重复，弹窗提示次数；用户确认后继续。
6. 系统生成草稿目录和剪映 JSON 文件。
7. 旁白和音乐复制到草稿本地 `assets/audio`。
8. 工作台记录草稿生成信息。
9. 用户打开剪映专业版继续添加视频、裁剪和发布。

## 8. 异常处理

- 文件移动失败：回退本次已移动文件。
- 模型调用失败：记录失败日志并提示原因。
- 可恢复的 429、5xx 或网络错误：最多自动尝试 3 次。
- 剪映目录无效：阻止生成，要求重新确认目录。
- 音乐被草稿引用：禁止删除。
