# 产品需求文档

## 1. 产品定位

电商视频生产工作台是电商运营平台中的视频生产模块。它不是自动成片系统，而是面向真实运营流程的素材和草稿生产工具。

核心原则：

- 人工做业务判断。
- 系统做重复性文件、模型和草稿工作。
- 模型结果必须人工确认。
- 工作台输出剪映草稿，不输出最终成片。

## 2. 功能范围

### 2.1 素材归类

- 产品名称可新增、修改、删除和分页查看。
- 标签分类和标签名称可新增、修改、删除和分页查看。
- 标签跨产品通用，以“标签分类 + 标签名称”共同唯一。
- 用户通过系统原生多文件选择器选择一个或多个原视频。
- 每条视频至少选择一个标签。
- 同一条视频在同一标签分类下只能有一个标签名称。
- 确认归类后，系统移动原视频，不复制、不导入代理。
- 移动成功后记录原路径、现路径、媒体信息、产品和标签。

### 2.2 内容文库

- 文案库保存已采纳的短标题和长口播稿。
- 输入参考文案后，模型分析语言风格、受众和专家角色，并生成 5 条候选。
- 参考原文自动进入文案库并视为已采纳。
- 候选文案支持采纳或不采纳，不采纳必须填写原因。
- 当前 5 条候选全部审核后，才允许继续迭代。
- 删除分析记录不删除已采纳文案；删除文案库内容不损坏历史迭代记录。

### 2.3 音频转文案

- 支持抖音视频短链接、本地视频和本地音频。
- 模型识别结果可以人工修改。
- 只有人工点击保存后才进入文案库。
- 音频转文案不创建旁白资源。

### 2.4 音色库与字幕配音

- 音色库使用官方基础音色目录，固定序号 1–597。
- 首次试听真实调用模型并入库存音频，后续试听复用库存文件。
- 字幕配音通过音色序号解析 voice 参数。
- 配音输入可手动填写，也可从文案库模糊联想选择。
- 生成结果包含旁白音频和字幕时间轴。
- 旁白与字幕经人工确认后才能用于剪映草稿。

### 2.5 背景音乐

- 支持本地音频/视频上传。
- 支持从短视频分享链接提取音频。
- 音乐可试听、改名、打自定义标签和删除。
- 被剪映草稿引用的音乐禁止删除。
- 当前不保存 BPM、节拍点、波形或卡点分析数据。

### 2.6 剪映草稿

- 用户选择文案、旁白/字幕和背景音乐。
- 视频片段不由系统写入，用户进入剪映后手动添加、裁剪和排列。
- 系统生成无视频轨道或空视频轨道的剪映专业版半成品草稿。
- 草稿直接写入用户确认的剪映草稿目录，不生成 ZIP。
- 重复使用相同素材组合生成草稿时提示历史次数，但不阻止继续生成。

### 2.7 模型配置与日志

- 模型配置包含文案生成、音频转文案、字幕配音三张卡片。
- 每张卡片独立保存接口地址、API Key 和模型 ID。
- 配置完整即使用，不设置启用复选框。
- 连接测试和模型列表读取不计入真实业务调用。
- 真实生成、识别、合成进入脱敏日志。

## 3. 权限和安全

- API Key 和 Secret 不得进入模型调用日志。
- Base64 和二进制内容不落库，只保存摘要、大小和媒体信息。
- 日志失败不得阻断业务结果。
- 删除数据库记录不得隐式删除已经移动到用户素材盘的原视频。

## 4. 交互要求

- 涉及移动、上传、提取、生成、读取模型列表等耗时动作，必须立即显示处理中状态。
- 处理中禁止重复提交。
- 浏览器刷新后应恢复服务端任务状态。
- 删除操作使用页面中央确认弹窗，不依赖浏览器原生确认框。
