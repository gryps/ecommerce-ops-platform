# 素材归类规范

## 1. 素材来源

视频素材由用户通过系统原生多文件选择器选择。系统直接操作用户选择的原视频文件，不创建导入副本，不创建粗剪代理。

## 2. 产品目录

确认归类后，系统在素材根目录下创建产品名称文件夹：

```text
素材根目录/产品名称/
```

产品名称由人工确认。删除或修改产品主数据只影响数据库记录，不移动、不改名磁盘上的既有视频。

## 3. 文件命名

目标文件名由产品名称和标签组成：

```text
产品名称-标签1-标签2.扩展名
```

规则：

- 文件名不包含标签分类名称。
- Windows 非法字符必须安全替换。
- 不允许路径穿越。
- 重名时自动追加数字序号。

## 4. 标签规范

- 标签分类和标签名称是独立主数据。
- 标签跨产品通用。
- 唯一性由“标签分类 + 标签名称”共同保证。
- 每条视频至少一个标签。
- 同一条视频在同一标签分类下只能选择一个标签名称。
- 不同分类的标签可以同时存在。
- 删除标签分类会删除该分类下标签和视频标签关系，但不处理磁盘文件。

## 5. 批量选择

- 一次选择的一组视频只归属于一个产品。
- 视频默认不选中。
- 支持全选、取消全选、单选和批量选择。
- 点击标签时应用到当前选中的视频。
- 再选同分类其他标签会替换原标签。
- 点击全部选中视频都已有的同一标签，会批量移除。

## 6. 移动前校验

确认归类前必须完成：

- 源文件存在。
- 目标目录可用。
- 源路径在允许边界内。
- 扩展名属于支持的视频类型。
- 媒体信息可解码。
- 每条视频至少一个标签。
- 同一视频同一分类不存在多个标签。
- 目标重名可通过序号解决。

## 7. 移动与回退

- 全部校验通过后才开始移动。
- 批量移动中途失败时，回退本批已经移动的文件。
- 成功后记录原路径、现路径、媒体信息、产品和标签。
- 确认归类只负责本次移动与重命名，不持续追踪后续文件状态。
- 已归类文件允许再次被用户人工选择并重新归类。

## 8. 页面反馈

- 归类执行期间按钮必须显示移动中，并锁定重复提交。
- 浏览器刷新后继续查询服务端操作状态。
- 成功结果只显示在“素材归类”页顶部提示栏。
- 不在“产品与标签管理”中显示本次移动结果。
