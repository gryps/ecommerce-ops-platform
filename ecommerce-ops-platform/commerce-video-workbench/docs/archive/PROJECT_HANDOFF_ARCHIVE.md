### 2026-07-27 任务：文案内容库重构需求确认

#### 任务目标
- 避免日常标题、旁白内容迭代持续新增标题模板、字幕模板和框架。
- 将稳定的视觉样式与高频变化的文字内容彻底解耦。
- 建立可自动补库、人工审核、三个月去重并可追溯热点效果的文案库存。

#### 已确认方案
- 框架继续管理视觉与生产结构；标题/字幕模板改名为标题/字幕样式，只保存字体、位置和动画。
- 新增独立“文案内容库”二级标签，维护仅标题、仅字幕和标题字幕组合；框架另支持无文案模式。
- 内容按全局/产品、呈现方式、标题/旁白内容方向及字幕节奏规格分库存。
- 内容方向属于文案记录本身；框架不再重复固定方向，只在组成固定文案时用于筛选，热点效果
  以成片实际使用内容携带的方向追溯。
- 模型按库存阈值自动排队补库，生成结果必须人工采纳；不采纳原因作为下一轮负面反馈。
- 标题字幕组合允许分别审核，只有两侧都采纳后才能参与组合生产；通过后也可作为单项使用。
- 字幕保存有逻辑顺序的句子序列和时长占比，生成与预览读取目标时长、镜头数、剪辑节奏和 BPM。
- 文案按人工排序依次使用，同一使用形态三个月内不重复；渲染前占用，失败释放，成功后记入历史。
- 成片快照记录内容、内容方向、样式和框架版本；热点成片同时归因到框架、组合及标题/字幕单项。
- 现有标题/字幕文字迁移为默认已采纳内容，原视觉配置保留为样式，现有框架不因迁移新增。

#### 方案文档
- 完整需求：`../legacy/COPY_CONTENT_LIBRARY_REQUIREMENTS.md`
- 自动混剪总需求中的旧版文字模板规则已更新为新方案摘要。

### 2026-07-26 任务：GPT 专用代理与其他模型直连

#### 用户网络边界

- 可灵、阿里云素材分类、实拍混剪、音频提取和其他业务流量不应配置代理。

#### 排查结论
- WSL2 使用 `networkingMode=Mirrored`。
- 交互终端配置了 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:7890`。
- Web 与 worker systemd 服务没有继承代理变量。
- 代理/TUN 虚拟网卡 `198.18.0.1/30` 的默认路由 metric 为 1，抢占了局域网
  `eth1 / 192.168.31.31` 的 metric 25 直连路由。
- 两个已配置模型域名 DNS 正常，但经 TUN 默认路由连接超时。
- 显式使用 `127.0.0.1:7890` 时均快速返回 HTTP 401，证明代理通路正常。
- 强制绑定 `eth1` 直连时同样快速返回 HTTP 401，证明模型域名、DNS、TLS 和物理直连正常。
- 根因是 WSL 的 TUN 默认路由，而不是模型 API 或密钥。

#### 应用完成内容
- 模型配置新增“此模型专用代理”字段。
- 代理字段默认留空；留空时模型测试、模型列表和正式推理均不主动使用代理。
- 只有用户在 GPT 所在模型卡显式填写代理地址时，该模型调用才使用代理。
- 代理地址限定为 HTTP(S) URL。
- 模型代理设置随模型卡独立保存，不向其他模型或系统进程扩散。
- 前端明确提示“仅 GPT 需要时填写，非 GPT 留空”。

#### WSL 尚需人工完成
- 当前会话尝试降低 TUN 路由优先级时，`sudo` 要求管理员密码，未执行修改。
- 可在 WSL 终端人工执行：

### 2026-08-03 交接：确认无视频剪映草稿生成规则

#### 讨论结论

- 下一版“生产与剪映草稿”命名为“无视频剪映草稿生成”。
- 用户不在系统中选择视频，只选择文案、字幕、旁白和背景音乐；视频由用户进入剪映后人工添加。
- 草稿总时长取字幕最后结束时间、旁白时长和背景音乐时长中的最大值；文案不参与时长计算。
- 较短的旁白和背景音乐保持原始长度，不循环、不拉伸、不补静音。
- 文案生成从 0 秒持续至草稿结束的文字轨道；字幕直接使用库存时间轴，不重新识别或对齐。
- 系统自动检测本机剪映草稿目录，展示完整路径并由用户确认；检测失败时允许手动选择或填写，校验后保存为后续优先目录。
- 直接在目的目录创建草稿文件夹，不压缩 ZIP、不复制媒体；同名目录禁止覆盖并自动追加递增序号。
- 目录检测和草稿生成必须具有明确的处理中、成功、失败状态并阻止重复提交。
