# 08 MVP 开发任务拆分

## 开发原则

- 每个任务尽量控制在一个模块内。
- 每次实现前只读相关文档。
- 先做纵向最小闭环，再做体验优化。
- 外部 API 和 ComfyUI 都先用 mock adapter 跑通。

## Phase 0：项目骨架

- 初始化后端 FastAPI 项目。
- 初始化前端 Next.js 项目。
- 建立 `projects/` 文件目录规范。
- 建立基础配置加载。
- 建立 SQLite 数据库连接。

验收：

- 前端能访问后端健康检查。
- 后端能创建项目目录。

## Phase 1：领域模型与项目管理

- 实现 Project、Product、Asset、Shot、PromptSet、GenerationTask、ShotVersion 表。
- 实现项目创建、查询、看板接口。
- 实现商品档案接口。

验收：

- 可以创建项目。
- 可以录入商品资料。
- 可以查看项目详情。

## Phase 2：资产管理

- 实现资产上传。
- 实现资产分类和标签。
- 实现项目目录落盘。
- 实现资产列表查询。

验收：

- 上传商品图后文件进入项目目录。
- 数据库记录资产元信息。

## Phase 3：AI 导演与提示词

- 实现脚本生成接口，可先使用 mock LLM。
- 实现分镜生成接口。
- 实现 PromptSet 结构化生成。
- 实现提示词渲染模板。

验收：

- 一个商品可以生成 15 秒脚本。
- 脚本可以拆成 5 个镜头。
- 每个镜头有结构化提示词。

## Phase 4：ComfyUI 集成

- 实现 ComfyUI 连接检测。
- 实现 workflow 注册。
- 实现 workflow 参数映射。
- 实现 mock workflow。
- 再接真实 ComfyUI `/prompt`。

验收：

- 可以对某个镜头生成关键帧任务。
- 输出图片绑定到镜头。

## Phase 5：视频 Provider Adapter

- 定义标准视频请求和响应。
- 实现 MockVideoProvider。
- 实现 Vidu 或 MiniMax 首个真实 adapter。
- 实现任务提交、轮询、下载。
- 实现成本估算。

验收：

- 可以从镜头提交图生视频任务。
- 任务完成后生成 ShotVersion。
- 成本记录写入数据库。

## Phase 6：审核与导出

- 实现镜头版本对比。
- 实现通过、淘汰、返修意见。
- 实现素材包导出。
- 实现剪辑清单导出。

验收：

- 选择每个镜头最终版本。
- 导出视频片段、提示词、字幕和成本报告。

## 推荐第一个纵向闭环

```text
创建项目
-> 录入商品
-> 上传商品图
-> 生成 5 个镜头
-> 生成每个镜头提示词
-> mock 生成视频
-> 审核选择
-> 导出素材包
```

这个闭环不依赖真实厂商 API，适合先验证产品结构和数据流。
