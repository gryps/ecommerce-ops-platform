# 01 产品概要

## 产品定位

AI 商品宣传片制作系统是一个面向商品推广视频的 AI 导演工作台。系统将商品资料、资产管理、脚本分镜、提示词生成、ComfyUI 本地工作流、厂商视频 API 和镜头审核串成标准生产流程。

## 核心用户

- AI 导演：负责创意、脚本、分镜、镜头审核。
- 电商运营：负责商品资料、卖点、平台发布需求。
- 设计/修图：负责商品图、人物图、环境图、道具图处理。
- 技术人员：负责 ComfyUI 工作流和厂商 API 配置。
- 剪辑师：负责最终成片剪辑、字幕、配音、包装。

## MVP 目标

1. 创建项目和商品档案。
2. 上传并分类商品、人物、环境、道具、风格资产。
3. 生成 15 秒推广视频脚本和镜头分镜。
4. 为每个镜头生成结构化提示词。
5. 调用 ComfyUI 生成或修复关键帧。
6. 调用至少一个视频厂商 API 生成视频。
7. 管理镜头多版本结果、返修意见和通过状态。
8. 导出剪辑素材包。
9. 记录项目成本和任务失败原因。

## 标准流程

```text
项目创建
-> 商品档案
-> 资产上传
-> 卖点提炼
-> 创意方向
-> 脚本
-> 分镜
-> 提示词
-> 关键帧
-> 视频生成
-> 审核返修
-> 导出
```

## MVP 不做

- 不做完整剪辑软件。
- 不做模型训练平台。
- 不做素材交易市场。
- 不要求完全本地离线视频生成。
- 不在业务逻辑中绑定某一个厂商 API。

## 首批推荐场景

优先做“单品 15 秒商品推广视频”。原因是流程完整、复杂度可控、验证速度快。

镜头建议：

1. 产品氛围开场，2-3 秒。
2. 核心卖点展示，3 秒。
3. 使用场景或人物互动，4 秒。
4. 产品细节特写，3 秒。
5. 品牌/商品收尾，2 秒。
