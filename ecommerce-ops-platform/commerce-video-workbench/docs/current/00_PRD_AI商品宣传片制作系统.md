# AI商品宣传片制作系统 PRD

版本：v0.1  
日期：2026-08-16  
产品定位：面向商品推广视频的 AI 导演工作台，结合本地 ComfyUI 资产/关键帧生产能力与第三方视频生成 API，标准化完成从商品资料、创意脚本、分镜、提示词、视频生成到成片交付的全流程。

## 1. 背景

商品宣传片的传统制作依赖导演、摄影、灯光、美术、剪辑、后期等多角色协作，成本高、周期长、试错慢。AI 视频模型已经能够承担部分文生视频、图生视频、参考生视频任务，但实际商用仍存在以下问题：

- 商品外观、Logo、包装文字容易不一致。
- 人物、场景、道具缺少统一资产管理。
- 提示词依赖个人经验，难以复用和追踪。
- 多模型 API 价格、质量、时长、比例、失败率不透明。
- 生成过程缺少镜头级版本管理，返修成本高。
- ComfyUI 工作流能力强，但不适合非技术人员直接操作。

本产品目标是把“AI 导演经验、商品广告制作方法、ComfyUI 工作流、厂商视频 API”封装为可复用的软件系统。

## 2. 产品目标

### 2.1 核心目标

1. 将商品宣传片制作流程标准化为：商品建档 -> 资产整理 -> 卖点提炼 -> 脚本生成 -> 分镜设计 -> 关键帧生成 -> 视频生成 -> 剪辑交付。
2. 支持文生视频、图生视频、首尾帧视频、参考素材生视频等多种生产方式。
3. 支持对接多个视频模型 API，并按质量、价格、速度、适用场景推荐模型。
4. 用 ComfyUI 负责本地资产处理、产品图增强、人物一致性、关键帧生成、局部重绘、放大修复等任务。
5. 建立镜头级提示词、参数、模型、成本、结果、返修意见的追踪体系。

### 2.2 非目标

- v1 不做完整 NLE 剪辑软件替代，不替代 Premiere、剪映、DaVinci。
- v1 不做模型训练平台，只支持 LoRA/参考图/工作流调用。
- v1 不承诺完全本地离线视频生成，视频生成主路径对接厂商 API。
- v1 不做开放素材交易市场。

## 3. 用户角色

| 角色 | 诉求 |
|---|---|
| AI 导演/创意负责人 | 快速完成创意方向、脚本、分镜、镜头调度 |
| 电商运营 | 批量生成商品短视频，用于抖音、小红书、淘宝、视频号 |
| 设计师/修图师 | 处理商品图、场景图、人物图、Logo 和视觉规范 |
| ComfyUI 技术人员 | 管理工作流、节点参数、模型、API 对接 |
| 剪辑师 | 获取镜头素材、字幕、配音文案和成片结构 |
| 项目负责人 | 查看进度、成本、版本、交付物 |

## 4. 典型使用场景

### 4.1 单品 15 秒推广视频

用户上传商品图、包装图、卖点资料，系统生成 15 秒短视频脚本和 5 个分镜。用户确认后，系统为每个镜头生成首帧图和视频片段，最终导出剪辑包。

### 4.2 电商批量混剪素材

用户导入 20 个商品，每个商品生成 5 条不同风格的视频素材：产品特写、使用场景、人物推荐、卖点展示、价格促销。

### 4.3 品牌统一风格视频

用户配置品牌色、Logo、字体、画面风格、禁用词、参考广告片，系统在不同商品之间保持统一视觉调性。

### 4.4 人物口播/展示类视频

用户上传人物三视图、服装图、表情参考和商品图，系统生成角色一致的展示镜头、手持商品镜头、口播辅助画面。

## 5. 业务流程

```text
创建项目
  -> 商品资料录入
  -> 资产上传与分类
  -> 品牌规范配置
  -> 卖点提炼
  -> 创意方向选择
  -> 脚本生成
  -> 分镜生成
  -> 提示词生成
  -> 关键帧生成/修图
  -> 视频 API 生成
  -> 结果筛选与返修
  -> 成片素材包导出
```

## 6. 功能需求

### 6.1 项目管理

| 功能 | 描述 | 优先级 |
|---|---|---|
| 创建项目 | 设置项目名称、商品类别、目标平台、视频比例、目标时长 | P0 |
| 项目看板 | 展示脚本、分镜、生成中、待审核、已通过、已导出状态 | P0 |
| 成本统计 | 统计每个项目、每个镜头、每个模型的 API 消耗 | P0 |
| 版本管理 | 脚本、分镜、提示词、生成结果均保留版本 | P1 |

### 6.2 商品资料管理

| 功能 | 描述 | 优先级 |
|---|---|---|
| 商品档案 | 名称、品类、价格带、目标人群、核心卖点、禁忌描述 | P0 |
| 商品图片 | 正面、侧面、背面、包装、细节、使用效果图 | P0 |
| 商品识别 | 自动提取颜色、材质、形状、Logo、包装文字 | P1 |
| 卖点提炼 | 根据资料生成卖点、痛点、场景、利益点 | P0 |

### 6.3 资产管理

资产类型：

- 商品图：主图、包装图、细节图、材质图、Logo。
- 人物图：正面、侧面、背面、表情、服装、手部动作。
- 环境图：室内、户外、门店、直播间、办公室、厨房等。
- 道具图：桌面、杯子、包装盒、背景布、工具、装饰物。
- 风格参考：竞品广告、摄影风格、灯光风格、构图参考。
- 音频资产：旁白、BGM、音效、品牌音色。

| 功能 | 描述 | 优先级 |
|---|---|---|
| 上传资产 | 支持图片、视频、音频、文档 | P0 |
| 资产分类 | 按商品、人物、环境、道具、风格、音频分类 | P0 |
| 资产标签 | 自动/手动添加标签，如高端、清透、科技、生活方式 | P1 |
| 资产评分 | 标记资产质量、可用性、是否推荐使用 | P1 |

### 6.4 AI 导演脚本模块

| 功能 | 描述 | 优先级 |
|---|---|---|
| 创意方向生成 | 根据商品和人群生成 3-5 个创意方向 | P0 |
| 脚本生成 | 生成 5s、15s、30s 视频脚本 | P0 |
| 分镜生成 | 拆分镜头编号、时长、景别、动作、运镜、画面说明 | P0 |
| 导演点评 | 对分镜节奏、卖点表达、镜头可实现性给出修改建议 | P1 |
| 平台适配 | 抖音、小红书、淘宝、视频号等不同平台话术和节奏 | P1 |

### 6.5 提示词生成模块

提示词采用结构化模板，不只生成一整段自然语言。

字段包括：

- 镜头类型
- 主体描述
- 商品描述
- 人物描述
- 场景描述
- 动作描述
- 运镜描述
- 光线描述
- 材质细节
- 广告风格
- 一致性约束
- 负面提示词
- 模型参数建议

| 功能 | 描述 | 优先级 |
|---|---|---|
| 文生视频提示词 | 从分镜生成 T2V 提示词 | P0 |
| 图生视频提示词 | 结合首帧/尾帧生成 I2V 提示词 | P0 |
| 关键帧提示词 | 生成 ComfyUI 出图提示词 | P0 |
| 负面词生成 | 自动生成产品防变形、人物防畸形、文字防污染负面词 | P0 |
| 多模型适配 | 对不同 API 生成不同格式提示词 | P1 |

### 6.6 ComfyUI 工作流模块

本地 ComfyUI 负责以下任务：

- 商品图清理、背景移除、放大。
- 商品关键帧生成。
- 人物一致性图生成。
- 场景图生成。
- 首帧/尾帧生成。
- 局部重绘与瑕疵修复。
- 视频后处理：补帧、超分、降噪、调色预处理。

| 功能 | 描述 | 优先级 |
|---|---|---|
| 工作流注册 | 保存 ComfyUI workflow JSON、输入参数、输出路径 | P0 |
| 工作流调用 | 通过 ComfyUI API 调用本地工作流 | P0 |
| 参数映射 | 将商品、资产、提示词映射到工作流输入 | P0 |
| 结果回收 | 自动保存输出图/视频并绑定到镜头 | P0 |
| 失败重试 | 节点失败、显存不足、超时等状态记录 | P1 |

### 6.7 视频模型 API 模块

首批支持模型方向：

- MiniMax Hailuo / H3 API
- 可灵 Kling
- Vidu

- 其他 OpenAI-compatible 或代理 API

| 功能 | 描述 | 优先级 |

| 模型配置 | 配置模型名、时长、比例、分辨率、价格、能力 | P0 |
| 任务提交 | 提交文生视频、图生视频、首尾帧、参考生视频任务 | P0 |
| 轮询/回调 | 查询任务状态，下载生成结果 | P0 |
| 成本记录 | 记录预估成本、实际扣费、失败是否收费 | P0 |
| 模型推荐 | 根据镜头类型推荐性价比模型 | P1 |

### 6.8 镜头生产与审核

## 14. 风险与约束

- 厂商 API 价格、能力和模型名称变化频繁，需要配置化。
- 商品 Logo 和包装文字在视频生成中容易变形，需要关键帧和后期合成兜底。
- 人物手部、拿取商品动作仍是高风险镜头，应优先使用图生视频和动作参考。
- 视频 API 审核可能导致失败或延迟，需要记录失败原因。
- 本地 ComfyUI 工作流对显存、模型路径、节点版本敏感，需要环境检测。
- 商用素材版权、人物肖像授权、音乐版权需要在项目层面记录。
