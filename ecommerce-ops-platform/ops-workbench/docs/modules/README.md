## 固定前置

开发前仍需先读：

- `/mnt/e/codexwork/PROJECT_MEMORY.md`
- `/mnt/e/codexwork/AGENTS.md`
- `../../../docs/DEVELOPMENT_COLLABORATION.md`

若本目录文档与 `PROJECT_MEMORY.md` 冲突，以 `PROJECT_MEMORY.md` 和用户最新口径为准。

## 任务沟通格式

后续开发优先按以下格式限定上下文和改动边界：

```text
模块：
范围：
目标：
禁止：
验收：
执行：
```

如果用户没有写清楚，先把需求拆成这 6 项再动手。

## 前端细节定位

调整按钮、文本、对齐、间距、弹窗、缩略图、表格列等前端细节时，优先要求或使用以下定位信息：

```text
前端修改：
页面：
区域：
元素文字：
当前问题：
期望效果：
不要动：
验收：
执行：
```

如果有截图，以截图红框/箭头和页面文字为准；如果只改界面表现，应明确不改后台接口和业务逻辑。
