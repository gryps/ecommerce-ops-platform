# 业务模型调用日志与资源用量需求

## 定位

本功能位于“模型配置”，仅供管理员调试所有当前及未来业务模型的真实调用。
不提供费用字段，不作为计费系统。

## 记录边界

- 只统计真实业务调用；连接测试、获取可用模型列表不记录、不汇总。
- 每次实际请求尝试单独写一条，成功、失败和自动重试都计数。
- 同一逻辑业务调用使用 `call_id` 分组，并记录 `attempt_number`。
- 关联业务步骤，以及批次、素材、产品、生产任务或模板等业务对象，但不提供跳转。
- 记录接口实际返回的输入、输出和总 Token；接口未返回时明确标记，不做估算。
- 记录响应耗时；成功、失败和重试均进入平均耗时。

## 内容与安全

- 保存完整输入提示词及原始响应，落库前统一脱敏。
- API Key、Secret、Bearer、手机号、邮箱等敏感信息不得进入明细。
- 不保存视觉文件副本；只保存路径、SHA-256、字节数、尺寸和帧数。
- Base64 或其他二进制正文不保存，只保存类型、字节数和 SHA-256。
- 明细无需额外加密，但只能由管理员访问。
- 日志写入使用独立数据库事务；日志失败不得影响、回滚或阻塞原业务结果。

## 留存与汇总

- 调用明细保留 3 天，每个北京时间自然日自动执行过期清理。
- 每个模型的按日汇总永久保留。
- 人工可清空单模型调用明细，必须二次确认，且不得删除汇总。
- 汇总范围为今日、近 7 日、全部；近 7 日按 `Asia/Shanghai` 自然日。
- 统计调用、成功、失败、输入/输出/总 Token、Token 返回次数和平均耗时。

## 界面

- 每张模型配置卡显示汇总和近 7 日趋势，并支持立即刷新。
- 自动刷新间隔沿用总览中的业务模型状态轮询间隔。
- 最近 5 条默认折叠。
- “查看全部”固定 10 条/页、最新优先，不提供筛选和搜索。
- 详情使用对话框，显示结构化业务信息和脱敏后的输入/响应 JSON。
- 不提供复制原始 JSON。
