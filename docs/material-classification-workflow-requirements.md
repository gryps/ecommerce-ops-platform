# 素材分类模型应用需求说明（V1）

> 历史兼容说明：本文描述的自动分类、审核和入库链路已于 2026-08-01 退出当前工作台主流程。
> 当前原视频移动归类规则以 `docs/JIANYING_DRAFT_WORKFLOW_REQUIREMENTS.md` 为准。

## 1. 产品定位

产品归类用于把新导入的视频归入正确的产品，并将分类结果写入产品资料库。

产品资料库是产品、视频素材、分析特征、分类规则、使用历史和混剪素材池的统一管理中心；分类模型只是产品资料库的一种自动入库工具，并不等同于产品资料库本身。

当前实现不再为对象分类单独上传抽帧。低码率整段视频只上传一次给“素材视频理解”模型，
同一次返回同时包含产品、背景、动作完整性、重复动作和淘汰时间线；产品归类随后复用该结果，
只追加一次批次级文本归并。对象属性分类（颜色）因必须精确区分主体与背景，才条件化追加
主体 BBOX 定位和本地颜色计算。

为了支持自动化生产，产品归类配置放在工作流第一步“素材批次”中。批次创建后，系统自动完成视频分析和产品归类；工作流执行到产品资料库节点时，必须保证相应视频已完成分类及必要审核。

## 2. 适用范围

- V1 仅处理视频素材，不处理图片等其他素材类型。
- 一个素材批次只能选择一种产品归类方式，不能在同一批次中混用多种方式。

## 3. 产品归类方式

| 归类方式 | 适用场景 | 示例 | 是否调用分类模型 |
| --- | --- | --- | --- |
| 直接指定产品 | 整批视频均属于同一产品 | 一批素材全部是同一款产品 | 不进行产品识别，但仍提取混剪特征 |
| 对象分类 | 视频中包含不同类型的主体 | 飞机、汽车、牙签 | 复用整段视频理解 |
| 对象属性分类（颜色） | 主体类型相同，只能通过颜色区分 | 不同颜色的仿造花 | 复用整段理解，并补充 BBOX |

### 3.1 直接指定产品

用户创建批次时可以选择项目内已有产品，也可以当场创建新产品。系统不再审核产品归属，
后续整段视频理解仍提取背景、主体位置、模特动作和镜头时间线；不为已指定产品默认追加 BBOX。

特征提取失败时，视频仍正常进入指定的产品资料库，但暂时不能参与混剪，也不影响其他可用视频继续生产。

### 3.2 对象分类

系统根据批次提示词识别视频中的主要主体，不要求用户预先填写候选类别。

- 通过完整低码率视频的连续画面识别唯一主体；
- 根据提示词选择画面中的主要产品；
- 返回主体类别、模特动作、置信度和判断理由；
- 多个主体无法确定唯一主产品时进入待确认；
- 在当前项目内跨产品资料库进行产品语义匹配；
- 高置信度匹配已有产品，不存在时自动创建新产品；
- 无法可靠匹配时进入待确认，避免产生重复产品；
- 不得跨项目匹配。

### 3.3 对象属性分类（颜色）

V1 只支持根据主体颜色分类，暂不设计其他对象属性。

处理链路：

```text
视频自动抽帧
→ 模型根据提示词识别主体
→ 模型返回主体 BBOX
→ 本地计算 BBOX 内的主体颜色
→ 综合多帧颜色
→ 匹配项目级颜色区间
→ 归入已有产品或创建新产品
```

颜色判断要求：

- 综合所有有效帧；
- 使用主体区域中占比最高且跨帧最稳定的颜色；
- 每条视频只得到一个最终产品归属；
- 优先沿用项目内已有颜色区间；
- 新颜色无法落入已有区间时，自动建立新颜色区间及对应产品；
- 自动生成便于理解的产品名称，例如“浅粉色仿造花”；
- 颜色区间根据人工纠正持续调整；
- 颜色区间只在当前项目内生效。

## 4. 素材批次配置

创建批次时配置：

- 产品归类方式；
- 直接指定的已有产品或新产品名称，或批次分类提示词；
- 当前项目的审核运行模式。

对象分类和对象属性分类均提供系统默认提示词，用户可以按需修改。用户提示词只描述要识别的主体或分类目标；主体类别、BBOX、模特动作、置信度和结构化返回格式等要求由系统提示词固定追加。

批次开始处理后禁止直接修改归类方式和提示词。如需修改，应创建新配置版本并重新执行。

批次保存以下快照：

- 归类方式；
- 用户提示词；
- 系统提示词版本；
- 模型版本；
- 颜色区间版本；
- 项目分类规则版本。

## 5. 视频特征提取

无论采用哪一种归类方式，系统都执行首次视频分析。

### 5.1 条件化帧级数据

仅对象属性分类（颜色）或确需精确定位时抽取代表帧，每个有效抽帧保存：

- 抽帧时间点；
- 主体 BBOX；
- 主体颜色；
- 背景颜色；
- 主体位置；
- 模特动作；
- 模型置信度；
- 分析状态。

素材视频理解模型负责识别主体、背景、模特动作及完整时间线。条件化定位调用负责 BBOX；
本地负责计算主体颜色、背景颜色和主体位置，保存特征并执行颜色区间及相似度判断。

### 5.2 视频级数据

系统综合全部有效帧生成唯一主体类别、稳定主体颜色、代表性背景颜色、主体位置特征、模特动作特征、综合置信度和最终产品归属。

主体颜色与背景颜色必须分开计算和保存：主体颜色用于对象属性分类，背景颜色用于后续混剪镜头匹配。

### 5.3 异常条件

出现以下情况时视频进入待确认：

- 多数抽帧未检测到主体；
- BBOX 跨帧不稳定；
- 存在多个主体且无法确定唯一主产品；
- 对象类别置信度不足；
- 产品语义匹配不可靠；
- 主体颜色无法稳定计算；
- 无法可靠归入已有颜色区间。

异常视频只暂停自身分支，不阻塞其他视频和产品。

## 6. 产品资料库人工审核

产品资料库按模型识别出的产品分组展示视频素材、抽帧缩略图、主体 BBOX、模型识别结果、主体颜色、背景颜色及待确认原因。

支持：

- 整组或批量通过；
- 将单个或多个视频改分到已有产品；
- 创建新产品并将视频移入；
- 确认待确认视频的产品归属。

V1 不提供手动编辑 BBOX，不限制审核角色，也不要求记录审核操作日志。

## 7. 审核运行模式

### 7.1 强制人工审核

- 所有自动分类成功的视频都必须人工审核；
- 待确认视频必须人工处理；
- 审核前暂停对应视频的后续流程；
- 可以按产品分组逐组审核；
- 某产品组通过后立即启动该产品流程，无需等待整个批次。

直接指定产品的素材无需再审核产品归属。

### 7.2 自动通过分类

用户认可系统准确率后，可在项目级手动切换：

- 高置信度结果自动通过并进入后续生产；
- 低置信度、主体识别失败或颜色无法归类的视频仍进入待确认；
- 异常视频只暂停自身分支；
- 系统不能自行开启该模式，只能提示用户；
- 纠错率上升时提示用户决定是否切回强制审核。

## 8. 准确率与规则训练

系统统计人工审核通过率、纠错率和待确认率，并按项目整体、分类方式和具体产品分别展示。

人工纠正作为当前项目的监督样本，用于训练和调整：

- 产品语义匹配规则；
- 主体颜色区间；
- 背景颜色相似度规则；
- 主体位置相似度规则；
- 模特动作相似度规则。

每次规则更新生成新版本并保留旧版本。新版本自动重新处理尚未人工确认的待确认视频，不回溯修改已自动分类成功或已人工确认的视频。

人工确认产品后可以先解除产品归属阻塞，系统随后在后台重新分析并补齐颜色、主体位置和动作特征。

## 9. 工作流集成

直接指定产品在素材登记后立即完成。对象分类和颜色分类在媒体准备及逐条整段视频理解后执行，
从已保存结果做批次归并，不重复上传视频或抽帧做产品识别。

```text
媒体准备与本地技术检查
→ 低码率整段视频理解（逐条）
→ 原片按可用时间线切片
→ 批次级产品归并（一次文本调用）
→ 分类完成且审核条件满足
→ 写入或关联产品
→ 形成产品级素材集合
→ 启动该产品后续生产

分类仍在执行
→ 产品资料库节点等待
→ 分类完成后自动恢复

单个视频待确认
→ 只暂停该视频
→ 其他视频继续

媒体准备、色彩元数据、解码、代理或后续模型审片异常
→ 进入对应素材批次的“待处理异常”
→ 不建立独立的常规质量审核阶段
→ 人工处理后自动恢复该素材分支

单个产品组审核完成
→ 立即启动该产品流程
→ 不等待整个批次
```

整段视频理解失败只暂停对应素材；其他素材的镜头和产品结果继续保存。批次文本归并或 BBOX
补算失败只重试对应辅助步骤，不得重新上传已经成功理解的视频。重试及重新执行必须幂等，
不得重复创建产品、视频记录或后续任务。

重新执行历史批次时使用批次保存的原颜色区间、模型、提示词和规则版本，保留人工确认或修正结果，只重新处理自动分类结果和待确认素材。

## 10. 产品级生产与跨批次素材池

后续工作流以产品为单位执行。同一产品的混剪素材可以来自当前批次、当前项目其他历史批次，以及已经参与过历史混剪的视频，但不得跨项目取材。

产品审核完成后立即启动生产。可用且符合去重要求的镜头不足时进入“等待素材”，后续批次补充合格素材后自动恢复。

## 11. 混剪镜头选择和重复限制

一次混剪的候选镜头需要属于同一产品、同一背景组，同时优先选择主体位置和模特动作不同的镜头。
背景、主体位置和动作相似度用于本次成片内部的多样性排序，不作为三个月历史硬去重条件。

三个月历史复用只按完全相同的候选片段 ID 统计，且只查询成功渲染的历史成片。新成片中近三个月
已使用镜头数不得超过总镜头数的 30%；详细计算、任务时序和失败处理以
`docs/AUTOMATIC_MIX_REQUIREMENTS.md` 为准。

## 12. 核心状态

```text
批次归类状态：
未开始 → 分析中 → 部分完成 → 已完成
                     ↘ 执行失败

视频状态：
分析中
→ 待审核
→ 审核通过
→ 待确认
→ 已人工纠正
→ 特征补算中
→ 可参与混剪
→ 特征异常/暂停混剪

产品生产状态：
等待审核
→ 可生产
→ 生产中
→ 等待素材
→ 已完成
```

“部分完成”表示部分产品或视频已满足后续条件，其他素材仍在分析、审核或待确认，不阻塞已完成分支。

## 13. V1 明确不做

- 图片素材分类；
- 颜色以外的对象属性分类；
- 同一批次混用多种归类方式；
- 手动调整主体 BBOX；
- 跨项目产品匹配、混剪取材或规则训练；
- 系统自动开启无人值守模式；
- 审核角色限制；
- 审核操作日志。

## 14. 验收标准

1. 创建批次时可以选择三种产品归类方式。
2. 两种自动分类方式均支持默认提示词和用户修改。
3. 批次启动后配置不可直接修改，并保存完整版本快照。
4. 每条低码率视频只进行一次整段视觉理解，并保存产品、背景、动作及三类时间线。
5. 对象分类能在项目内语义匹配并避免重复创建产品。
6. 颜色分类能沿用项目颜色区间并自动创建新颜色产品。
7. 所有自动分类结果可在产品资料库中通过缩略图审核。
8. 支持按产品分组审核、批量通过和批量改分。
9. 两种审核模式能够正确阻塞或放行素材。
10. 单个异常视频不会暂停整个批次或其他产品。
11. 人工纠正形成项目级训练反馈并生成规则版本。
12. 产品审核通过后立即启动产品级生产。
13. 混剪可以跨批次使用同产品历史素材。
14. 三个月重复限制按候选片段 ID 和 30% 数量上限生效，背景、位置和动作只用于成片内部多样性排序。
15. 分类重试和重新执行不产生重复数据或任务，辅助字段失败不会触发整段视频重复上传。
